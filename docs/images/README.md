# Screenshot Placeholders for Along AI Demonstration

This document lists the required product screenshots for the Along AI documentation. The project owner can capture these images from the live deployment or local demo.

## Required Screenshots

1. `mobile_chat.png`: Mobile conversational chat interface showing user booking in Nigerian Pidgin or Hausa.
2. `quote_card.png`: Interactive fare quote card displaying corridor route, pickup filling station, per-seat price, and discount.
3. `ride_card_boarding_code.png`: Confirmed ride card showing the 4-digit boarding code (OTP), meeting anchor, and shareable link.
4. `ai_xray_panel.png`: AI X-ray panel displaying extraction intent, resolved landmarks, model provider, and execution latency.
5. `driver_terminal.png`: Driver companion cockpit displaying passenger manifest, OTP verification field, and seat count.
6. `live_tracker_in_transit.png`: Family and public live trip tracker in transit showing route progress, next landmark, and demo driver badge.
7. `live_tracker_mobile.png`: Live trip tracking interface rendered on a mobile viewport.

## Specifications

- Format: PNG
- Placement: Store in this directory (`docs/images/`)
- References: Linked relatively in `README.md` as `docs/images/<filename>.png`
